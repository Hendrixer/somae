# Sender icon sources

Retrieved 2026-10-10. These monochrome SVGs are copied without changing their vector paths from [LobeHub Icons](https://github.com/lobehub/lobe-icons), revision `c385b2b8d1f9e19aa86e628d4e23c91ee1111a47`.

- `claude.svg`: [Claude source](https://github.com/lobehub/lobe-icons/blob/c385b2b8d1f9e19aa86e628d4e23c91ee1111a47/packages/static-svg/icons/claude.svg).
- `chatgpt.svg`: [OpenAI source](https://github.com/lobehub/lobe-icons/blob/c385b2b8d1f9e19aa86e628d4e23c91ee1111a47/packages/static-svg/icons/openai.svg), used to identify a ChatGPT sender in this local prototype.

Claude is a trademark of Anthropic. OpenAI and ChatGPT are trademarks of OpenAI. These icons identify example senders; they are not Somae branding or an endorsement. See [OpenAI design guidelines](https://openai.com/brand/) and [Claude](https://claude.com/).

The source uses `currentColor`. For an external image element this defaults to black; the interface can use the SVG as a CSS mask to render the supplied monochrome shape on its dark surface. The path geometry and proportions are preserved.
