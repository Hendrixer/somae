## Outcome

Use the Electrobun desktop app to message a real local Claude Code session, receive a document and image, review their actual content, submit precise feedback, receive linked revisions, approve a specific version, then restart the app and retrieve originals, versions, feedback and decisions from its library.

## Settled scope

- Desktop only for this test. Electrobun replaces the earlier Tauri direction; use a Bun main process with a native webview.
- Claude Code uses the person's existing subscription login. Somae is a two-way chat channel, not a new creation agent. Support configured terminal sessions and sessions launched by Somae on the same machine.
- A local custom MCP channel receives messages and provides explicit acknowledgement, reply and artifact tools. Persist configuration once, supply channel enablement on each launch. Initial development-channel confirmation is part of supported setup. No ACP requirement and no claim to attach to arbitrary unconfigured live processes.
- Cloudflare hosts the API and original files under getsomae.ai. Use a private single-person bootstrap with local credentials; no account/signup product flow. A local agent remains local, with the established initiation/continuation boundaries.
- Documents and images first. Text-anchored comments, suggested replacements, image-region comments, saved drafts, one deliberate batch submission and linked revisions. The response follows the originating signal: `ask_question` keeps its exact choices or free-text answer and optional artifact comments; `request_review` offers Approve / Request changes and optional comments. Questions never gain a review decision or approval stamp. Answer either interaction from the canvas without a second response in the inbox. No audio/video or arbitrary app preview requirement in this test.
- The library preserves original bytes, stable item identity, immutable versions, related work, feedback and exact approved-version pointers. A newer version never silently replaces an approved one.
- Signal remains the chosen visual language and quick queue. The native companion smoothly transitions to content measured at the destination width within the active screen; review and library center on the usable display, and returning compact restores the previous position; longer content keeps scrolling. AppKit owns the transition clock, repeated targets do not restart it, and Reduce Motion keeps sizing immediate. Closing it leaves an optional floating Wave/count/shortcut widget. Cmd comma opens a separate Settings window with persistent Electric, Infrared and After hours themes and reduced-motion preferences. Open a larger still review canvas/library when needed. Preserve all earlier prototypes, Wave and canonical design tokens.
- No task tracker. Agent execution remains the agent's responsibility. Delivery and input acknowledgement remain distinct from results.

## Build and evidence

1. **Real channel proof:** send into an authenticated Claude session; inspect explicit acknowledgement and reply-tool output; publish actual files and send follow-up feedback. Local protocol tests are additional checks, not a substitute for this proof.
2. **Native shell:** build and run an actual Electrobun macOS app, with summon/hide and local session controls. A browser-only page is not the deliverable.
3. **Durable service:** reuse the shared domain guards, persist communication and its outbox atomically, retain original file bytes, and enforce audience-scoped views and bootstrap credentials. Verify actual Worker behavior, not just reference tests.
4. **Review and revisions:** use the real document/image pair; attach feedback to exact content versions; answer a question using its exact offered choice or free text with optional comments, or approve/request changes for an explicit content-review request. Each interaction submits one response and feedback delivery; a question answer leaves decision history and approval pins unchanged. Return a new version through the same session; reject stale submissions and duplicate sends safely. Keep question and review controls mutually exclusive, preserve full-width comment separators, and never infer an approval from question wording or labels.
5. **Library and recovery:** close/reopen, retrieve originals and earlier versions, preserve approval pins and drafts, and show disconnected/unknown delivery outcomes honestly.
6. **Finish:** run the extended repository verification gate, native build and integration checks; review desktop/narrow UI and keyboard/focus/draft/advance behavior; exercise the real end-to-end flow. Deploy and validate the authorized Cloudflare service/domain once CLI access is available.
